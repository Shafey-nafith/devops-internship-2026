## Lab 1 — SSH into your VM with local port forwarding

SSH into your VM using local port forwarding so that a port on your host machine forwards to a port inside the VM. Install a simple web server on the VM, then access it from your host browser through the tunnel.

**Write down:** the command you used and confirm the page loaded.

---

## Lab 2 — Inspect HTTP versions with curl

Use `curl` to fetch response headers from a website using HTTP/1.1 and again using HTTP/2.

**Write down:** both outputs and note what is different between them.

---

Answer these questions in your notes:
